# Кубики Music Flow — сборка под Timeweb Cloud

Статическая страница без единого обращения наружу. Ни CDN, ни Google Fonts:
библиотеки и шрифты лежат рядом с файлом, поэтому страница не зависит ни от
Cloudflare, ни от доступности зарубежных сервисов.

## Что внутри

```
index.html                 страница целиком, 49 КБ
fonts.css                  подключение шрифтов, 24 начертания
fonts/*.woff2              Onest (400–800) и Space Mono 700, латиница и кириллица
lib/three.min.js           three.js r128 — трёхмерная сцена
lib/cannon.min.js          cannon.js 0.6.2 — физика броска
```

Всего около 1,2 МБ, из них 589 КБ — three.js.

## Куда это класть

В Timeweb **Cloud** нет обычного хостинга с каталогом `public_html`. Под статику
там два пути.

### Путь первый: Хранилище S3 плюс CDN — проще, Git не нужен

1. **Хранилище S3** → создать бакет, тип доступа **публичный**.
2. Загрузить в корень бакета содержимое этой папки: `index.html`, `fonts.css`
   и каталоги `fonts` и `lib`. Саму папку `dice-site` внутрь не класть —
   пути в разметке относительные.
3. В настройках бакета открыть **«Веб-сайт»** и указать индексный документ
   `index.html`.
4. Проверить по техническому адресу вида `имя-бакета.website.twcstorage.ru`.
   Если на этом шаге всё работает, дальше остаётся только домен.
5. Там же: **«Привязать собственный домен»** → **«Создать CDN-ресурс»** →
   добавить `music-flow.ru`.
6. В разделе **«Домены и SSL»** прописать DNS-записи так, как попросит панель
   при создании CDN-ресурса. Обновление занимает 15–20 минут.
7. Сертификат выпускается в настройках CDN-ресурса.

### Путь второй: App Platform — если файлы лежат в Git

Деплой из GitHub, GitLab или Bitbucket, сертификат бесплатный, при пуше в
репозиторий сайт обновляется сам. Удобнее на длинной дистанции, но требует
репозитория, а доступ к GitHub из России с мая 2026 нестабильный — заливать
придётся через VPN.

## Про деньги

Цены сверять на странице тарифов: в обзорах они расходятся. Ориентиры на
октябрь 2026: хранение S3 около 1 ₽ за гигабайт в месяц, фиксированный тариф на
10 ГБ — 79 ₽ в месяц, бесплатный лимит исходящего трафика 100 ГБ в месяц, сверх
него 1,3 ₽ за гигабайт. App Platform заявлен «от 1 ₽ в месяц», но что входит в
эту цену для статики, по открытым источникам не ясно.

Страница весит 1,2 МБ. Ста гигабайт бесплатного трафика хватает примерно на
восемьдесят тысяч открытий в месяц.

## Если что-то не так после заливки

**Текст есть, кости не появились.** Не нашлись `lib/three.min.js` и
`lib/cannon.min.js`. Проверить, что каталог `lib` лежит рядом с `index.html`,
а не уровнем выше или ниже.

**Шрифт не тот.** Не подхватился `fonts.css` или каталог `fonts`.

**Кости не появились, и в консоли ругань на MIME-тип.** Хранилище отдаёт
`.js` с неправильным типом. В свойствах объекта выставить
`application/javascript`. Шрифтам `.woff2` правильный тип не обязателен,
браузер их опознаёт сам.

**Проверка на главное.** Открыть вкладку «Сеть» в консоли: все запросы должны
идти только на свой домен. Если появился `fonts.googleapis.com` или
`cdnjs.cloudflare.com` — залит файл из артефакта, а не этот.

## Локальный просмотр

Открывать `index.html` двойным щелчком бесполезно: от адреса `file://`
относительные пути к библиотекам не разрешаются. Нужен любой веб-сервер:

```bash
cd dice-site && python3 -m http.server 8765
```

Дальше `http://localhost:8765`. То же самое поднимается из панели редактора —
конфигурация лежит в `.claude/launch.json` под именем `dice-site`.

## Чем отличается от версии в артефакте

Артефакт на claude.ai обязан брать библиотеки с разрешённых там CDN, поэтому
существует два варианта одного файла. Различий ровно три:

| | артефакт | эта сборка |
| --- | --- | --- |
| обвязка документа | добавляет платформа | `<!doctype html>` в файле |
| шрифты | `fonts.googleapis.com` | `fonts.css` и каталог `fonts` |
| библиотеки | `cdnjs.cloudflare.com` | каталог `lib` |

Правки в разметке и скрипте нужно вносить в оба файла.

## Что страница хранит

Журнал бросков и выбранную тему — в `localStorage` браузера. Ни сервера, ни
базы не нужно, данные никуда не уходят.
